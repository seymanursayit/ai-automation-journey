# LLM API Fundamentals

This project covers the fundamentals of working with Large Language Models (LLMs) through APIs.

## Topics Covered

- Few-shot prompting
- Prompt improvement
- Tokenization analysis
- HTTP requests to LLM APIs
- OpenRouter API
- JSON responses

## Tasks

### 1. Prompting

- Customer review classification using a few-shot prompt
- Deep research with an LLM
- Iterative prompt improvement

### 2. Tokenization

Comparison of English and Ukrainian sentences using the OpenAI Tokenizer.

The analysis includes:

- Token count
- Average characters per token
- Comparison of tokenization results

### 3. OpenRouter API

A POST request was sent to OpenRouter using:

- Authorization header
- Content-Type header
- JSON request body
- A free LLM model

The model response was successfully received and analyzed.

## Learning Outcomes

Through this project, I practiced writing structured prompts, analyzing tokenization, working with HTTP requests, and communicating with an LLM through an API.
